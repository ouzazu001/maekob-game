# เกม AI มาตราตัวสะกด "แม่กบ"

เกมเพื่อการศึกษาสำหรับห้องเรียน — ผู้เล่นยืนหน้ากล้อง แล้วยกมือไป "ค้าง" ที่กล่องคำตอบที่ถูกต้อง
ตรวจจับท่าทางด้วย TensorFlow.js + MoveNet ทำงานทั้งหมดในเบราว์เซอร์ ไม่มีการส่งภาพออกนอกเครื่อง

## วิธีเล่น

1. เปิดหน้าเว็บ แล้วกรอกรหัสผ่านเพื่อเข้าสู่ระบบ
2. กด **เริ่มเกม** และอนุญาตให้ใช้กล้อง
3. ยืนห่างจากกล้องพอให้เห็นแขนทั้งสองข้าง
4. ยกมือไปค้างบนกล่องคำตอบที่ถูกต้อง จนแถบสีเหลืองเต็มกล่อง
   - ตอบถูก +10 คะแนน / ข้อ BONUS +50 / ตอบผิด −5 (ไม่ติดลบ)
5. จบเกมแล้วกรอกชื่อเพื่อบันทึกลงตารางคะแนน

## โหมดครู (ตั้งค่า)

- จำนวนโจทย์: 10 ข้อ (สุ่ม) หรือ 20 ข้อ
- สีกรอบคำศัพท์
- ความไวในการตอบ: ต้องค้างมือ 0.4 / 0.7 / 1.1 วินาที (เด็กเล็กควรใช้ค่าช้า)
- โหมดวิ่งซิกแซกกรวย (แสดงคำสั่งบนจอ)

การตั้งค่าและตารางคะแนนถูกเก็บใน `localStorage` ของเครื่องนั้น

## รันบนเครื่องตัวเอง

กล้องและระบบล็อกอินต้องการ `https` หรือ `localhost`:

```bash
python3 -m http.server 8899
# เปิด http://localhost:8899
```

## Deploy

โฮสต์ผ่าน GitHub Pages (branch `main`, โฟลเดอร์ราก) — push แล้วอัปเดตอัตโนมัติ

## หมายเหตุเรื่องรหัสผ่าน

รหัสผ่านถูกตรวจฝั่งเบราว์เซอร์ โดยเก็บเป็นค่า SHA-256 ในไฟล์ (ไม่ใช่รหัสตรง ๆ)
กันได้แค่ระดับ "ไม่ให้คนทั่วไปเปิดเล่น" เท่านั้น — คนที่เปิดดูโค้ดหน้าเว็บสามารถข้ามได้
ถ้าต้องการความปลอดภัยจริง ต้องมีเซิร์ฟเวอร์ตรวจสอบให้

เปลี่ยนรหัสผ่าน: คำนวณ hash ใหม่แล้วแก้ค่า `PASSWORD_HASH` ใน `index.html`

```bash
printf 'รหัสใหม่' | shasum -a 256
```
