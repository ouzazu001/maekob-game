# เกม AI มาตราตัวสะกด "แม่กก"

เกมเพื่อการศึกษาสำหรับห้องเรียน — ผู้เล่นวิ่งไป "แตะ" กล่องคำที่สะกดด้วยมาตราแม่กก
ตรวจจับท่าทางด้วย MediaPipe Pose ทำงานทั้งหมดในเบราว์เซอร์ ไม่มีการส่งภาพออกนอกเครื่อง

## วิธีเล่น

1. เปิดหน้าเว็บ แล้วกรอกรหัสผ่านเพื่อเข้าสู่ระบบ
2. อนุญาตให้ใช้กล้อง รอระบบ AI โหลดเสร็จ แล้วกด **เริ่มเกม**
3. ยืนห่างจากกล้องพอให้เห็นแขนทั้งสองข้าง จะเห็นจุดสีแดงทาบอยู่ที่ข้อมือและนิ้วชี้
4. เอามือไปแตะกล่องคำตอบที่เป็นแม่กก
   - ตอบถูก +10 คะแนน / ตอบผิด −5 / ตอบถูกติดกัน 5 ข้อได้โบนัส +50
5. จบเกมแล้วกรอกชื่อเพื่อบันทึกลงตารางคะแนน

## ใช้บนแท็บเล็ต

- ตั้งแท็บเล็ตบนขาตั้งให้มั่นคง แนะนำ **แนวนอน** จะเห็นภาพกว้างกว่า
- ยืนห่างประมาณ **1.5–2 เมตร** ให้กล้องเห็นแขนทั้งสองข้าง
- ภาพจากกล้องกลับซ้ายขวาเหมือนส่องกระจก จุดแดงจะตรงกับมือจริงเสมอ

## โหมดครู (ตั้งค่า)

- จำนวนโจทย์: 10 ข้อ หรือ 20 ข้อ (ทั้งหมด)
- สีกล่องคำตอบ: ชมพู-ฟ้า หรือ ส้ม-เขียว
- โหมดวิ่งซิกแซกกรวย (แสดงคำสั่งบนจอ)

ตารางคะแนนถูกเก็บใน `localStorage` ของเครื่องนั้น (คีย์ `maekok_leaderboard`)
ส่วนการตั้งค่าโหมดครูมีผลเฉพาะรอบที่เปิดหน้าเว็บอยู่

## รันบนเครื่องตัวเอง

กล้องและระบบล็อกอินต้องการ `https` หรือ `localhost`:

```bash
python3 -m http.server 8899
# เปิด http://localhost:8899
```

## หมายเหตุเรื่องรหัสผ่าน

รหัสผ่านถูกตรวจฝั่งเบราว์เซอร์ โดยเก็บเป็นค่า SHA-256 ในไฟล์ (ไม่ใช่รหัสตรง ๆ)
กันได้แค่ระดับ "ไม่ให้คนทั่วไปเปิดเล่น" เท่านั้น — คนที่เปิดดูโค้ดหน้าเว็บสามารถข้ามได้
ถ้าต้องการความปลอดภัยจริง ต้องมีเซิร์ฟเวอร์ตรวจสอบให้

เปลี่ยนรหัสผ่าน: คำนวณ hash ใหม่แล้วแก้ค่า `PASSWORD_HASH` ใน `index.html`

```bash
printf 'รหัสใหม่' | shasum -a 256
```
